## Lambda 参数详情

各参数计算过程（新标准）:

1. **信息完整性 (info)**
   - 条件：E_average = 2 时，得分 = 50
   - 方程：50 = 100 * exp(-λ1 * 2)
   - 解得：λ1 = -ln(0.5)/2 = ln(2)/2 ≈ 0.346574

2. **语言质量 (lang)**
   - 条件：E_average = 4 时，得分 = 50
   - 方程：50 = 100 * exp(-λ2 * 4)
   - 解得：λ2 = -ln(0.5)/4 = ln(2)/4 ≈ 0.173287

3. **逻辑连贯性 (logic)**
   - 条件：E_average = 1 时，得分 = 50
   - 方程：50 = 100 * exp(-λ3 * 1)
   - 解得：λ3 = -ln(0.5) = ln(2) ≈ 0.693147
